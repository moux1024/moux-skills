# Release Checklist

Generate this checklist for upload, review, or production release tasks. Do not execute upload, review submission, or production release without explicit confirmation.

- AppID is real and correct.
- WeChat DevTools or `miniprogram-ci` access is available for the requested action.
- Trial version uploaded successfully before review.
- Service category matches the app.
- User privacy protection guide is updated.
- Payment, phone, location, album, camera, and other permission descriptions are complete where relevant.
- Subscribe message templates are configured where relevant.
- Content security and moderation are handled for user-generated content.
- Review version description is ready.
- Reviewer account or review instructions, if needed, are handled directly in the WeChat platform and not stored as plaintext secrets in the project.
- Production release is confirmed after review approval.
